# WPCC v76 — Page-by-page Codex bundles

Each numbered folder contains:

- `PROMPT.md` — the detailed Codex implementation prompt for that page/feature.
- `screenshots/` — every v76 prototype screenshot relevant to that prompt, including tabs, sheets, search/filter, empty/success states where applicable.

Use `MASTER_CODEX_PROMPT.md` once at the beginning of the Codex session. Then work through one numbered page folder at a time.

For Souls and Counselling, v76 has Home entry points but no dedicated prototype destination screen. Their folders therefore contain the Home screenshot plus a note telling Codex to inspect the existing app and not invent a destination UI unless required.
