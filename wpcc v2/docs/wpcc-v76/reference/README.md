# Reference folder

This folder contains the shared visual and architecture references used by every page prompt.

- `prototype-v76.html` — complete approved v76 interactive prototype
- `design-system.html` — current shared visual design system
- `design-system-addendum.md` — v76 interaction/motion additions
- `database-architecture.md` — suggestive data architecture guidance
- `screen-inventory.md` — complete screen/state inventory
- `full-prd.md` — full product requirements document
- `contact-sheet.jpg` — overview of captured prototype screenshots

Page prompts reference these files with `../reference/...`.

The screenshots specific to each page remain beside that page's `PROMPT.md` inside its `screenshots/` folder.
